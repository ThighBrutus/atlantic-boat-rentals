# Atlantic Boat Rentals — editable website concept

Open `index.html` in any browser to preview the site. This is a clean static site, so the visual layout and copy are easy to change in a standard editor, and it can be deployed to Netlify, Vercel, GitHub Pages, or a regular web host.

## Updating the site

- Click **Customize page** on the lower right of the live page to change highlighted copy or drag whole sections. Those changes are saved only in the browser you are using.
- Permanent edits live in `index.html` (copy), `styles.css` and `booking-map.css` (look and layout), and `script.js` (booking and editor behavior).
- The booking form currently demonstrates the full customer experience and confirms the request in-page. To receive actual inquiries, connect `bookingForm` in `script.js` to the company email, a booking service such as FareHarbor/Checkfront, or a form endpoint before publishing.

## Before launch

1. Replace the placeholder photo URLs with owned boat, staff, and marina photos.
2. Add real fleet inventory, rates, waiver details, and cancellation policy.
3. Connect the booking form to the chosen booking calendar/payment provider.
4. Confirm the official street address—the existing website shows both 101 and 125 N. Riverside Drive.
